# Malik — Creative Portfolio

Portofolio personal dengan tema Emerald Noir, dibuat menggunakan HTML, CSS, dan JavaScript murni.

## Menjalankan
1. Ekstrak folder `malik-portfolio`.
2. Buka folder tersebut di Visual Studio Code.
3. Buka `index.html` di browser, atau gunakan ekstensi Live Server untuk preview otomatis.

## Kustomisasi
- Edit teks, navigasi, dan proyek di `index.html`.
- Ubah warna, layout, dan responsivitas di `style.css` (variabel warna berada di bagian `:root`).
- Ubah interaksi di `script.js`.
- Ganti area foto placeholder pada bagian About dengan foto milikmu. Untuk menampilkan foto, letakkan file foto di folder ini lalu ubah elemen `.portrait-placeholder` di `index.html` menjadi elemen `<img>` dengan path fotomu dan sesuaikan CSS.
- Ganti visual proyek konseptual dengan gambar karya final jika sudah tersedia.
- Tautan Instagram saat ini diarahkan ke `@mlesmorles`.

## Catatan
Google Fonts memerlukan koneksi internet. Jika offline, browser akan memakai font sans-serif cadangan.
